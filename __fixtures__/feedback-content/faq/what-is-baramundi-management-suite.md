# What is baramundi Management Suite?

**URL:** https://feedback.baramundi.com/faq/what-is-bms
**Published:** 2023-05-10
**Category:** General

---

baramundi Management Suite (bMS) is a unified endpoint management (UEM) solution that helps IT administrators manage, secure, and deploy software across Windows, macOS, Linux, iOS, and Android devices.

## Key Features

- **Software Deployment**: Automated software installation and updates
- **Patch Management**: OS and third-party application patching
- **Endpoint Security**: BitLocker management, compliance monitoring
- **Mobile Device Management**: iOS and Android device control
- **Inventory Management**: Hardware and software asset tracking

## Use Cases

- Corporate IT departments managing 100-10,000+ endpoints
- Healthcare organizations requiring HIPAA compliance
- Educational institutions managing student devices
- Manufacturing with industrial endpoint management needs
